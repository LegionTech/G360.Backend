## 🛠️ Getting Started

Follow these steps to set up and run the API locally.

### Prerequisites

Ensure you have the following installed on your local machine:
*   [.NET 8 SDK](https://microsoft.com)
*   An IDE like [VS Code](https://visualstudio.com)

### Local Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/LegionTech/G360.Backend.git
   cd G360.Backend
   ```

2. **Build and Run the API:**   
   dotnet build
   dotnet run --project LegionTech.G360.API/LegionTech.G360.API.csproj
   
   The API should now be running at `http://localhost:5050`.
